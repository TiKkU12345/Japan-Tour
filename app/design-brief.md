# Discover Japan | Design brief

- Design read: A curious, design-aware traveller should feel invited into a vivid, human Japan, not sold a generic package holiday.
- Concept spine: Japan, unfolding. Each region is a new fold in a travel journal, with discovery shaped by small moments.
- Delivery tier: cinema, using scroll-linked scene reveals and layered editorial imagery; generated video unavailable on the current account, so no fake video scrub is presented.
- Animation mode: animated-website, adapted to scroll-driven CSS reveals and image depth because cinematic video generation was unavailable.
- Locked palette: indigo #172653, vermilion #E34C3B, sakura #E7A6B5, ivory #F7F3E9, ink #20243A. The palette directly references Japanese textiles, shrine gates, blossoms and paper.
- Locked type: a high-contrast editorial serif for display headlines paired with a clean sans for navigation and body copy.
- Section plan: immersive hero; typographic editorial introduction; asymmetrical nine-region image grid; image-and-list experience feature; numbered journey catalogue; seasonal selector; enquiry form; compact footer.
- Asset plan: destination imagery, wordmark, favicon and social cover. Video-generation attempt failed on account-plan restrictions; image photography is used as an interim visual treatment.
- CTA inventory: Explore Japan (vermilion solid); Find your journey (quiet underline); Build a custom trip (underline); per-package arrow links; Send trip enquiry (vermilion solid).
- Functional states: responsive menu, seasonal guide selector, accessible form validation and an honest post-submit message explaining that no inbox is connected yet.
